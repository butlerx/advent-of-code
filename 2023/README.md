# Advent of Code 2023

Solutions for [Advent of Code 2023](https://adventofcode.com/2023) in Rust.

## Structure

- `src/bin/XX.rs` — Solution for each day (parts 1 and 2).
- `src/lib.rs` — Shared utilities for the year.
- `input/XX.txt` — Puzzle input for each day.

## Running

```sh
cargo run --package aoc_2023 --bin 01
```

## Testing

```sh
cargo test --package aoc_2023 --bin 01
```
